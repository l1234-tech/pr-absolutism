# Изображения для сайта "Просвещённый абсолютизм Екатерины II"

Эта папка предназначена для хранения изображений, используемых на сайте. Все изображения должны быть оптимизированы для веба и иметь соответствующие alt-тексты.

## Требования к изображениям

### Технические требования:
1. **Формат:** JPEG или PNG
2. **Размер:** Не более 1920x1080 пикселей
3. **Вес:** Не более 500 КБ на изображение
4. **Оптимизация:** Сжатие без потери качества

### Содержательные требования:
1. **Историческая достоверность:** Изображения должны соответствовать историческим оригиналам
2. **Качество:** Четкое, хорошо освещенное изображение
3. **Соответствие контексту:** Изображение должно иллюстрировать соответствующий исторический период

### Требования к использованию:
1. **Alt-тексты:** Все изображения должны иметь подробные alt-тексты для доступности
2. **Подписи:** При использовании в статьях добавлять краткие подписи
3. **Источники:** Указывать источник изображения при необходимости

## Инструкции по добавлению изображений

### 1. Загрузка изображений
1. Поместите изображения в эту папку (`/src/docs/media/images/`)
2. Используйте имена файлов, указанные в таблице выше
3. Убедитесь, что изображения соответствуют техническим требованиям

### 2. Использование в Markdown
Для вставки изображений в статьи используйте следующий синтаксис:

```markdown
![Alt-текст](media/images/имя_файла.jpg)
*Подпись к изображению. Источник: [Название источника](ссылка)*
```

Пример:
```markdown
![Портрет императрицы Екатерины II Великой](media/images/ekaterina_II.jpg)
*Портрет Екатерины II. Источник: Никитченко А.К. "ПОРТРЕТНОЕ ИСКУССТВО ЭПОХИ ДВОРЦОВЫХ ПЕРЕВОРОТОВ"*
```

### 3. Использование в HTML (если необходимо)
```html
<figure>
  <img src="media/images/ekaterina_II.jpg" alt="Портрет императрицы Екатерины II Великой">
  <figcaption>Портрет Екатерины II. Источник: Никитченко А.К. "ПОРТРЕТНОЕ ИСКУССТВО ЭПОХИ ДВОРЦОВЫХ ПЕРЕВОРОТОВ"</figcaption>
</figure>
```

## Методологическое значение изображений

Согласно исследованию Никитченко А.К., портреты императоров эпохи дворцовых переворотов имеют важное методологическое значение:

1. **Визуальная репрезентация власти:** Портреты служат визуальными записями правления
2. **Инструмент легитимации:** Использовались для создания и укрепления образа монарха
3. **Отражение политических изменений:** Показывают эволюцию представлений о власти
4. **Символика стабильности/нестабильности:** Визуальные образы отражают степень стабильности власти
