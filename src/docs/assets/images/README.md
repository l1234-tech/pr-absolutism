# Favicon для сайта

Для корректного отображения favicon необходимо добавить файл `favicon.png` в эту папку.

## Требования к favicon:
- Формат: PNG
- Размер: 32x32 пикселей или 64x64 пикселей
- Простой дизайн, соответствующий тематике сайта

## Альтернативные варианты:
1. Использовать иконку книги (соответствует теме исследования)
2. Использовать инициалы "ЕII" (Екатерина II)
3. Использовать символ короны

## Как создать favicon:
1. Создайте изображение 64x64 пикселей в графическом редакторе
2. Сохраните как PNG с именем `favicon.png`
3. Поместите файл в эту папку

## Временное решение:
До добавления реального favicon сайт будет использовать стандартную иконку браузера.
