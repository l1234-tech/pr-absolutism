# Эпоха дворцовых переворотов

## Эпоха дворцовых переворотов (1725-1762): системный кризис власти

### Общая характеристика периода

Эпоха дворцовых переворотов (1725-1762) представляет собой период политической нестабильности в Российской империи, характеризующийся частой сменой власти, борьбой придворных группировок и усилением роли гвардии в политических процессах.

### Хронология ключевых событий

| Дата | Событие | Значение |
|------|---------|----------|
| 1725 | Смерть Петра I, воцарение Екатерины I | Начало эпохи нестабильности |
| 1726 | Создание Верховного тайного совета | Узурпация власти аристократией |
| 1727 | Смерть Екатерина I, Петр II | Возвращение к мужской линии |
| 1730 | Смерть Петра II, «затейка» верховников | Попытка ограничения самодержавия |
| 1730-1740 | Правление Анны Иоанновны | «Бироновщина», укрепление самодержавия |
| 1740-1741 | Иван VI Антонович, регентство Анны Леопольдовны | Кризис легитимности |
| 1741 | Переворот Елизаветы Петровны | Возвращение к петровским традициям |
| 1762 | Переворот Екатерины II | Начало просвещённого абсолютизма |

### Политические термины эпохи

- **Дворцовый переворот** — смена власти силами гвардии и придворных группировок без участия широких слоёв населения
- **Верховный тайный совет (ВТС)** — высший орган власти (1726-1730), созданный при Екатерине I
- **Кабинет министров** — орган при Анна Иоанновне (1731-1741)
- **Фаворитизм** — система управления через приближённых (временщиков)
- **Кондиции** — условия ограничения самодержавия (1730 г.)

### Историографические подходы

#### Белова А.Т. - институциональный кризис
- Советская наука сместила фокус с политических институтов на социально-экономические
- Сенат после Петра I утратил реальную власть → её захватили придворные органы (ВТС)
- Ослабление Сената — закономерный этап трансформации системы
- Верховный тайный совет - власть концентрируется в узком элитном кругу
- Кабинет министров - отсутствие устойчивой структуры управления
- **Итог:** послепетровская власть - закономерный кризис, а не случайность

#### Филимонов Д.А. - системные проблемы
- Система держалась на личности Петра → после смерти распад
- Кризис престолонаследия (Устав 1722 г.) → борьба кланов становится нормой
- Политизация гвардии → армия как механизм смены власти
- Бюрократизация и коррупция → рост злоупотреблений
- Внешнеполитический фактор → влияние европейских стран на внутридворцовые отношения

#### Дубов А.В. - охранительная идея
- Усиление охранительной идеи после 1730 г.
- Попытка конституционализма вызывает отторжение
- Страх перед хаосом → общество делает выбор в пользу стабильности
- Стремление к стабильности → поиск устойчивой системы управления

#### Никитченко А.К. - визуальный анализ
- Портреты императоров как инструмент легитимации власти
- Образ слабого монарха (Петр III) → слабость легитимности
- Усиление абсолютизма через визуальный образ (Анна Иоанновна)
- Екатерина II — завершение эпохи через создание образа "просвещённой монархини"

### Ключевые выводы

1. Эпоха дворцовых переворотов показала институциональную нестабильность самодержавной модели
2. Кризис носил системный характер (престолонаследие, гвардия, бюрократия)
3. Попытки ограничения власти (1730 г.) вызвали страх перед хаосом
4. Общество и элита сделали выбор в пользу сильной власти
5. Однако простое усиление самодержавия не решало проблему легитимности
