# Инструкции по добавлению изображений на сайт

## Общая информация

Для приведения сайта к релизной версии необходимо добавить изображения портретов императоров и других визуальных материалов согласно исследованию Никитченко А.К. "ПОРТРЕТНОЕ ИСКУССТВО ЭПОХИ ДВОРЦОВЫХ ПЕРЕВОРОТОВ: ОБРАЗЫ ИМПЕРАТОРОВ".

## Папка для изображений

Все изображения должны быть размещены в папке:  
`/src/docs/media/images/`

## Технические требования

1. **Формат:** JPEG или PNG
2. **Размер:** Рекомендуется не более 1920x1080 пикселей
3. **Вес:** Оптимизировать до 500 КБ или меньше
4. **Качество:** Четкие, хорошо освещенные изображения

## Как добавить изображения

### Способ 1: Через интерфейс SourceCraft
1. Перейдите в папку `/src/docs/media/images/`
2. Нажмите "Добавить файл"
3. Загрузите изображение с правильным именем файла
4. Повторите для всех необходимых изображений

### Способ 2: Через инструменты разработчика
Если у вас есть локальная копия репозитория:
1. Поместите изображения в папку `src/docs/media/images/`
2. Зафиксируйте изменения
3. Отправьте изменения в репозиторий

## Проверка работы

После добавления изображений:

1. **Раскомментируйте блок с галереей** в файле `/src/docs/coups/index.md`
   - Удалите `<!--` в начале и `-->` в конце блока с галереей
   - Сохраните изменения

2. **Проверьте отображение** на сайте:
   - Перейдите на страницу "Эпоха дворцовых переворотов"
   - Убедитесь, что портреты отображаются корректно
   - Проверьте alt-тексты (наведите курсор на изображение)

3. **Добавьте изображения в другие разделы** при необходимости:
   - В раздел "Политика Екатерины II" добавьте портрет Екатерины II
   - В разделы о реформах добавьте соответствующие изображения документов

## Методологическое обоснование

Согласно исследованию Никитченко А.К., портреты императоров имеют важное значение для понимания эпохи:

1. **Визуальная репрезентация власти** - портреты как инструмент легитимации
2. **Отражение политических изменений** - эволюция образов монархов
3. **Символика стабильности/нестабильности** - визуальные индикаторы политической ситуации
4. **Инструмент пропаганды** - создание желаемого образа власти

## Дополнительные рекомендации

1. **Сохраняйте оригинальные названия файлов** для consistency
2. **Проверяйте alt-тексты** на соответствие содержанию изображений
3. **Оптимизируйте изображения** для быстрой загрузки страниц
4. **Указывайте источники** в подписях к изображениям
5. **Тестируйте на разных устройствах** - убедитесь в корректном отображении
