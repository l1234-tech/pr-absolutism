# Европейское влияние

Идеи европейского Просвещения оказали значительное влияние на формирование политических взглядов монархов XVIII века.

## Основные положения

- Влияние философов (Вольтер, Дидро)  
- Идея рационального управления государством  
- Заимствование административных моделей
